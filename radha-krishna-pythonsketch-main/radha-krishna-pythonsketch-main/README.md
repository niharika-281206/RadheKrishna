# 🪷 Radha Krishna Python Sketch (ASCII Art Generator)

A simple Python script to convert any image (like Radha Krishna) into detailed ASCII text art.

---

## 📋 Requirements

This project requires Python and the `Pillow` (PIL) library.

Install Pillow using pip:
```bash
pip install pillow
```

## 🚀 How to Run
1. Clone or download this repository.
2. Place your image file(e.g.. radha.jpg) in the same folder as radhakrishna.py.
3. Open radhakrishna.py and ensure the image filename matches your file at the bottom of the script: "image_to_ascii("radha.jpg", new_width =120)"
4. Run the script from the terminal: python radhakrishna.py
5. The ascii art will be printed directly in your terminal and automatically saved to a radha_ascii_art.txt file.
## ⚙️ Customization
* Image Width: Adjust new_width=120 to make the ASCII output wider or narrower.
* Different Image: Change "radha.jpg" to any other image name (e.g., "hanuman.jpg", "photo.png").
